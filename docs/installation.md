# Installation

The package is published on [PyPI](https://pypi.org/project/vitafit-ble/) and can be installed with `pip` (or any equivalent):

```bash
pip install vitafit-ble
```

## Python versions

vitafit-ble supports the Python version required by the latest stable release of [Home Assistant Core](https://github.com/home-assistant/core) and every later version, and tests them all. That's currently Python 3.14 and later.

Older versions back to Python 3.12 should work, but they're not tested, and support for them may be dropped in any release.
